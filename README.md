# Automação de Relatórios com Python, SQL e SQLite

## Objetivo

Este projeto demonstra a automação de análises de vendas utilizando Python, Pandas e SQLite.

Os dados são importados de arquivos CSV, armazenados em um banco de dados SQLite, processados através de consultas SQL e exportados para um relatório Excel.

## Tecnologias Utilizadas

* Python
* Pandas
* SQLite
* OpenPyXL
* Git
* GitHub

## Funcionalidades

* Leitura de arquivos CSV
* Criação automática de banco SQLite
* Inserção de dados em tabelas
* Consultas SQL com agregações
* Relatórios de faturamento por produto
* Ranking de clientes
* Exportação para Excel
